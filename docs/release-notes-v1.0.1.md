# FocusKeeper v1.0.1 — 等级直选 · 时长推荐 · 今日一句

## 中文

**新增**

- **等级直选**：`↑` / `↓` 键直接切换 初级（15 分钟）/ 中级（25 分钟）/ 高级（45 分钟），`←→` 仍可 ±5 分钟微调
- **时长推荐**：每次打开和收工后，按最近 3 次（14 天内）表现建议今天的时长——都达标且走神不密就加 10 分钟（上限 60），都没到就减 5 分钟（下限 10），单次表现不算数。**每条建议都带理由**，`↑↓←→` 永远有最终决定权
- **今日一句**：待机时显示一条有出处的真话——庄子、荀子、老子、苏轼、胡适、里尔克、村上春树……每天换一条，没有鸡汤，没有网红语录

**改进**

- 待机提示行、状态行写明等级键位
- 回归测试扩展到 45 项（新增 7 个推荐算法用例）

**下载**：下方附件 `专注计时器-便携版.zip`，解压双击 `FocusKeeper.exe` 即用（自带运行时，64 位 Windows，无需安装）。

## English

**Added**

- **Direct level selection**: `↑` / `↓` switches Beginner (15 min) / Intermediate (25 min) / Advanced (45 min); `←→` still fine-tunes by 5 minutes
- **Goal recommendation**: on every launch and after every session, suggests today's goal from your last 3 sessions (within 14 days) — all achieved with sparse distractions → +10 min (cap 60); all missed → −5 (floor 10); a single session never changes anything. **Every suggestion carries its reason**, and `↑↓←→` always has the final say
- **Line of the day**: while idle, shows one sourced quote — Zhuangzi, Xunzi, Laozi, Su Shi, Hu Shih, Rilke, Murakami... a new one each day. No chicken soup, no influencer quotes

**Improved**

- Idle hint and status line now state the level keys
- Regression tests extended to 45 checks (7 new cases for the recommender)

**Download**: the `专注计时器-便携版.zip` asset below. Unzip and run `FocusKeeper.exe` — self-contained, 64-bit Windows, no installation needed.
